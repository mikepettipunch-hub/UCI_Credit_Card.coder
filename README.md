# UCI_Credit_Card.coder
El dataset Default of Credit Card Clients (archivo UCI_Credit_Card.csv) reúne información de 30.000 clientes de tarjeta de crédito de un banco de Taiwán, con datos de abril a septiembre de 2005. Tiene 25 columnas:límite de crédito y el historial de los últimos 6 meses (estado de pago, monto facturado y monto pagado).
